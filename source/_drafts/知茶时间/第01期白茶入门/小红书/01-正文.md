## 正文标题
> **白茶到底是什么？看完这篇你就是朋友圈最懂茶的人 🍵**

---

六大茶类里最简单的一种👇

不炒不揉，只有两步：
**萎凋 + 干燥**

白茶=最接近茶叶本身味道的茶

——————————————

❓ **白茶为什么叫"白"？**

不是汤色白！
是因为芽叶上有一层细密的白毫
像覆了一层薄霜，银光闪闪✨
这层白毫就是白茶毫香的来源

——————————————

📊 **六大茶类一张图搞懂**

🟢 绿茶 → 杀青锁绿 → 龙井
⚪ 白茶 → 萎凋干燥 → 白毫银针
🟡 黄茶 → 杀青闷黄 → 君山银针
🟤 乌龙 → 半发酵摇青 → 铁观音
🔴 红茶 → 全发酵 → 正山小种
⚫ 黑茶 → 后发酵 → 普洱

——————————————

🏆 **白茶也有段位**

白毫银针 → 只取单芽，顶配，鲜到极致
白牡丹 → 一芽一二叶，**新手首选！性价比之王**👑
寿眉 → 叶片大，耐泡甜度高，适合煮着喝
贡眉 → 和寿眉类似，不用太纠结

——————————————

☕ **新手怎么泡？**

别被茶具劝退⬇️

懒人版：玻璃杯 + 2-3克茶 + 85℃水
进阶版：盖碗 + 3-5克茶 + 90-95℃水 + 15秒出汤

⚠️ 别急着倒！白茶越泡越甜

——————————————

💡 **白茶能放很久！**

新茶鲜爽 → 老茶醇厚
放3-5年会出枣香、药香🫖

但一定要：密封+避光+干燥+无异味
别听"要通风存放"，那是坑你
